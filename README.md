# Inkfinity

Inkfinity adalah aplikasi pemesanan layanan fotocopy dan print berbasis React Native Expo. Aplikasi ini dibuat untuk membantu pelanggan memilih layanan, membuat pesanan, dan melihat riwayat pemesanan secara sederhana.

## Fitur Aplikasi

- Halaman utama aplikasi
- Daftar layanan fotocopy dan print
- Form pemesanan layanan
- Detail pesanan
- Riwayat pemesanan
- Tampilan sederhana dan mudah digunakan

## Layanan yang Tersedia

- Print Hitam Putih
- Print Warna
- Fotocopy
- Scan Dokumen
- Jilid
- Laminating

## Teknologi yang Digunakan

- React Native
- Expo
- JavaScript
- Expo Go
- Google Fonts Crimson Text
